# VoxHelp 3.0

VoxHelp is a free multilingual communication web app designed for hospital patients who temporarily or permanently cannot speak, for example after a tracheostomy or during a period of aphonia.

The patient simply taps large buttons to communicate needs, discomfort, pain, emotions and everyday requests. The selected phrase is spoken aloud by the device.

## Use VoxHelp

https://wrelax1.github.io/voxhelp-3/

VoxHelp can be used directly in a web browser or installed on a smartphone or tablet as a Progressive Web App (PWA).

## Main features

- Large, simple buttons designed for hospital use
- Text mode or pictogram mode
- Patient interface available in French, English, German, Italian, Spanish and Portuguese
- Spoken communication in French, English, German and Italian
- Independent patient and caregiver languages
- Detailed pain-location communication
- Personal phrases
- Works on smartphones and tablets
- Works offline after installation
- No account required
- No personal data collection
- No advertising
- Free to use

## Privacy

VoxHelp does not require an account and does not transmit or store personal patient information.

Speech is generated locally using the text-to-speech voices available on the device.

## Offline use

After the first successful loading or installation, VoxHelp can operate without an Internet connection.

The application and its pictograms are stored locally by the browser through a Service Worker.

## Voices

VoxHelp uses the text-to-speech voices installed on the smartphone or tablet.

For correct pronunciation, the corresponding language voice must be installed on the device.

## Background

VoxHelp was developed after encounters with patients and caregivers in Geneva hospitals, with the aim of providing a simple communication aid when speaking is difficult or impossible.

VoxHelp is an independent project and is not presented as an official application of any hospital or healthcare institution.

## Technology

VoxHelp is a lightweight Progressive Web App built with:

- HTML
- CSS
- JavaScript
- Web Speech API
- Service Worker
- Web App Manifest

No server-side application or user database is required.
